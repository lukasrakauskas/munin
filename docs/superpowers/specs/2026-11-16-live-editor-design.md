# One-view live Markdown and command navigation

Replace the Write/Read split with one live-preview document. Inactive top-level Markdown blocks render normally, including tables and Mermaid; activating a block reveals its source in place. Every edit patches the exact byte range in the canonical TextEdit; no Markdown reserialization. Keep native IME/clipboard/selection behavior inside the active block, and canonical undo across blocks. Ctrl/Cmd+A promotes to a full-source selection surface for cross-document operations; Escape returns to live rendering. Boundary arrows move between blocks; boundary deletion edits the canonical document. Retain existing file safety, autosave, context menus and native-control clearance.

Approaches considered: rich-text import/export (lossy for Markdown/diagrams), separate reading pane (explicitly rejected by user), native block-level live preview (chosen). This is block-level live editing, not full CodeMirror feature parity. No new dependencies or framework pin changes.

RuneKit has no named command palette: its Palette module is theme colors. Reuse Dialog and TextInput and standard styled listbox rows for a centered responsive launcher, with fuzzy ranking, keyboard navigation, Enter, Escape, outside dismissal, visible shortcuts and empty results. Ctrl/Cmd+K combines files and actions; Ctrl/Cmd+P scopes commands; Ctrl/Cmd+O scopes files. Cache the workspace file list when opening the launcher, not on every keystroke. Keep recently opened files in session order. Actions route to the same handlers as shortcuts; file-open failures keep dirty buffers and the launcher/error visible.

Obsidian sources: official Editing shortcuts, Command palette, Quick switcher and Hotkeys docs at github.com/obsidianmd/obsidian-help. Adopt Mod+N/O/P/S/W, Mod+B/I formatting, native undo/clipboard, Mod+F note search, Mod+Shift+K line deletion. Mod+K intentionally overrides Obsidian's link binding per user request. Sidebar uses Mod+Backslash; open workspace is available via palette/button (not Mod+O). Only advertise implemented commands. Mod+E reveals/finishes the active block in place, not a separate pane.
